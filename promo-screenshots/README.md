# Frontier Football: website screenshots

Clean screenshots of every page with no device frames, for dropping into the
screen placeholders of a video template such as Envato Elements' "Creative Website Promo".

| Folder | Size | Use for |
| --- | --- | --- |
| `desktop-1080p/` | 1920x1080 | 16:9 monitor or browser slots |
| `desktop-16x10/` | 2880x1800 (1440x900 @2x) | laptop slots |
| `phone/` | 1170x2532 (390x844 @3x) | phone slots |
| `full-page/` | full length | slots where the screen scrolls |
| `home-scroll-1080p.mp4` | 1920x1080, 30fps | a moving screen: the home page scrolling top to bottom |

Pages: home, who-we-are, events, gallery, community, collaborate, contact.

To regenerate, run `npm run build && npm run serve`, then run `node source/cap1610.mjs`.
