# Frontier Football - video asset handoff

Source: https://frontier-football.vercel.app/ (live site, captured 8 October 2026).
Template reference: https://elements.envato.com/creative-website-promo-BLHR3VP

## What to use

- `screenshots/desktop/`: clean 1920 x 1080 page captures for landscape screen replacement slots.
- `screenshots/mobile/`: clean 430 x 932 responsive captures for phone screen replacement slots.
- `mockups/01-desktop-home-transparent.png`: homepage in a browser frame, transparent surroundings.
- `mockups/02-phone-home-transparent.png`: homepage in a generic phone frame, transparent surroundings.
- `mockups/03-responsive-showcase-3840x2160.png`: desktop and phone on a bone stage.
- `mockups/04-events-showcase-3840x2160.png`: Events on an ink stage.
- `mockups/05-mobile-trio-3840x2160.png`: Home, Events and Gallery phone composition.
- `PREVIEW.png`: quick contact sheet of the screen captures.

Use the clean screenshots inside the Envato template's existing devices; use the framed mockups as standalone cutaways. Avoid adding another device frame around an already framed mockup. Screenshot filenames describe the capture viewport. See `manifest.json` for actual exported dimensions.

## Editor notes

1. Import the pack into the editor used by the downloaded Envato project.
2. Open each replacement/screen placeholder and insert the corresponding clean screenshot.
3. Preserve proportions. Fit to the slot, then adjust the crop where needed; never stretch the page.
4. Landscape assets suit 16:9 slots. Mobile assets are 430:932; fit and adjust if the template phone uses a different ratio.
5. Render the actual project at the template's supported resolution and frame rate. The 4K mockups can be used in a 1080p output or a 4K output.

The Envato project files were not available during preparation, so exact placeholder dimensions, slot count, supported editor and preview timing remain unverified. This is a screenshot/mockup handoff, not a finished video. Your friend handles template access, its project setup, any music and the final render.

Website screenshots preserve the existing photography and visible credits. No ownership of third-party photographs, sponsor marks, music or the Envato template is transferred by this pack. The generic frames are original and contain no device-maker branding.

`build-mockups.py` regenerates the presentation PNGs from the supplied captures using Python and Pillow. The website screenshots themselves are frozen live captures; regeneration does not recapture the site.
